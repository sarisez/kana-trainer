# Kana Trainer

A web-based trainer for learning Japanese kana: Hiragana and Katakana.

## Demo

[Open Kana Trainer on GitHub Pages](https://sarisez.github.io/kana-trainer/)

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite

## Features

- Hiragana and Katakana training
- Level-based progression
- Multiple answer input methods
- Optional transliteration hints
- Light and dark themes
- Ukrainian and English localization

## Getting Started

### Installation

```bash
git clone https://github.com/sarisez/kana-trainer.git
cd kana-trainer
npm install
```

### Run locally

```bash
npm run dev
```
